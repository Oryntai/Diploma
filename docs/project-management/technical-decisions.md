# Технические решения

## Принятый стек (этап скелета)

- `fastapi`, `uvicorn`, `sqlalchemy` в backend.
- SQLite по умолчанию для простого локального запуска.
- Один профиль устройства в simulator (temperature sensor) как стартовая точка.

## Объем модели данных на первом шаге

- Сначала только базовые таблицы: `devices`, `telemetry_events`, `alerts`.
- Поле `device_id` в событиях/алертах оставлено текстовым, чтобы фиксировать unknown/spoofed sender без авто-доверия.

## Упрощение запуска

- Backend стартует из корня репозитория.
- Simulator поддерживает `--seed` для воспроизводимости.
- Добавлены небольшие автотесты для стабилизации регрессии.
